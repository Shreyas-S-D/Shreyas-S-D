## 🚀 What I'm Working On

### 🛡️ CrowdPatrol

**YOLOv8 + DeepSORT based real-time crowd monitoring and risk assessment system**

A computer-vision-based public safety system designed to monitor crowds through CCTV/video feeds and identify potentially risky crowd conditions.

**Current capabilities:**

* 👁️ YOLOv8 person detection
* 🎯 DeepSORT multi-object tracking
* 📊 Crowd density analysis
* 🌊 Optical-flow based crowd motion analysis
* ⚠️ Risk assessment engine
* 📈 Risk score smoothing & hysteresis
* 📹 Real-time video monitoring
* 📷 Multi-camera CCTV command center
* 🔥 Firebase integration
* 🖥️ Streamlit monitoring interface
* 💾 Video output and monitoring metrics
* 📡 Support for external/live camera sources

**Tech:** `Python` `YOLOv8` `OpenCV` `DeepSORT` `PyTorch` `Firebase` `Streamlit`

---

### 🏠 SmartSpaces

**AI-driven architectural planning & sustainability analysis system**

SmartSpaces combines AI-assisted architectural planning with sustainability analysis to generate practical floor-plan concepts based on user requirements.

**Features:**

* 🏗️ Automated floor-plan generation
* 🖼️ Image-based floor-plan processing
* 👁️ OpenCV-based computer vision
* 🛏️ Requirement-based room planning
* 📐 Standard / Compact / Open layouts
* 🌱 Sustainability scoring
* 🌍 CO₂ reduction estimation
* ⚡ Energy-saving analysis
* 💧 Water-conservation analysis
* 📄 Automated sustainability reports

**Tech:** `Python` `Flask` `OpenCV` `NumPy` `Matplotlib` `ReportLab`
